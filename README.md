<summary>⚙️ <b>GitHub Action — Auto-Update Wild Pokémon (Click to expand setup guide)</b></summary>

### Step 1: Create `.github/workflows/daily-pokemon.yml`

```yaml
name: 🌿 Daily Wild Pokémon

on:
  schedule:
    - cron: '0 6 * * *'   # Runs every day at 06:00 UTC
  workflow_dispatch:        # Allows manual trigger

permissions:
  contents: write

jobs:
  update-pokemon:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3

      - name: Set up Python
        uses: actions/setup-python@v4
        with:
          python-version: '3.11'

      - name: Install dependencies
        run: pip install requests

      - name: Update README with new Pokémon
        run: python scripts/update_pokemon.py

      - name: Commit changes
        run: |
          git config --global user.email "action@github.com"
          git config --global user.name "PokéBot"
          git add README.md
          git diff --quiet && git diff --staged --quiet || \
            git commit -m "🌿 Wild Pokémon updated!"
          git push
```

### Step 2: Create `scripts/update_pokemon.py`

```python
import requests, random, re

pokemon_id = random.randint(1, 151)  # Gen 1 only — expand as desired
data = requests.get(f"https://pokeapi.co/api/v2/pokemon/{pokemon_id}").json()
name = data["name"].capitalize()
sprite = (
    f"https://raw.githubusercontent.com/PokeAPI/sprites/master"
    f"/sprites/pokemon/versions/generation-v/black-white/animated/{pokemon_id}.gif"
)

new_block = f"""
<img src="{sprite}" width="96" alt="Today's Pokémon"/>

**Today's Companion: {name}** `#{pokemon_id:03d}`
"""

with open("README.md", "r") as f:
    content = f.read()

# Replace between the two marker comments
content = re.sub(
    r"(<!-- PLACEHOLDER.*?-->).*?(<!-- END PLACEHOLDER -->)",
    f"\\1{new_block}<!-- END PLACEHOLDER -->",
    content,
    flags=re.DOTALL
)

with open("README.md", "w") as f:
    f.write(content)

print(f"Updated to {name} (#{pokemon_id})")
```
